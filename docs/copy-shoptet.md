## 4) ŠABLONA PRODUKTOVÉHO POPISU

Struktura pro každý nový produkt (krátký popis = benefit headline; dlouhý popis
= odstavec + parametry + kompatibilita):

**Krátký popis (p-short-description), 1–2 věty — benefit, ne vlastnost:**
```
[Co produkt dělá pro zákazníka + hlavní odlišnost.]
Např.: „Autospinner s integrovaným airflow roztočí pearls bez directional capu — plná chuť při nižší teplotě."
```

**Dlouhý popis:**
```
[ODSTAVEC — příběh/benefit, 3–5 vět: pro koho je, čím vyniká, jak se používá.]

Parametry:
- Materiál: [borosilikát / quartz / titan…]
- Joint size: [10 mm / 14 mm] · úhel [45° / 90°]   ← POVINNÉ u bangerů, slurperů, rigů
- Rozměry: [výška × průměr]
- [Další: tloušťka dna, průměr bucketu (pro carb cap!), objem…]

Kompatibilita:
- Sedí na: [rigy s 14mm/90° female jointem…]
- Doporučené příslušenství: [carb cap 25 mm, terp pearls 6 mm, cleaning kit]

[U ručního skla: autor, rok, "kus je unikát — prodáváme přesně ten z fotek".]
Prodej pouze osobám starším 18 let.
```

**Pravidla:**
- Vždy tykání, žádné zmínky o užívání látek — jen vybavení a jeho vlastnosti.
- Joint size + úhel uvádět VŽDY u skla se spojem (rig, banger, slurper, adaptér).
- U carb capů uvádět průměr bangeru, na který sedí.
- Cross-sell na konci popisu: 2–3 konkrétní doplňky (viz sekce 6 níže).
